## 🎮 Présentation du Jeu

**Neo Survivors Idle** est un jeu hybride qui combine :
- 🔄 **Incrémental/Idle** : Accumulation passive de ressources même hors-ligne
- ⚔️ **Auto-battler** : Combat automatique avec gestion stratégique
- 🏃 **Survivors-like** : Vagues infinies d'ennemis et améliorations au fil du temps

### Caractéristiques Principales

| Caractéristique | Description |
|-----------------|-------------|
| 🌐 100% Client-side | Aucun serveur requis, tout tourne dans le navigateur |
| 💾 Sauvegarde locale | Progression stockée via `localStorage` |
| ⏰ Gains hors-ligne | Continue de progresser même en fermant l'onglet |
| 🎨 Rendu WebGL2 | Graphismes WebGL2 natif fluides |
| 🔊 Audio procédural | Sons générés dynamiquement |

---

## 🎯 Objectif du Jeu

1. **Survivre** aux vagues d'ennemis infinies
2. **Collecter** l'Essence ⚡ et les Fragments ✦
3. **Améliorer** vos statistiques et production passive
4. **Consolider** pour obtenir des bonus permanents
5. **Optimiser** votre build pour atteindre des vagues toujours plus hautes

## 🖥️ Interface

L'interface est organisée en **trois colonnes** :

```
┌─────────────────┬─────────────────────────┬─────────────────┐
│   STATISTIQUES  │         ARÈNE           │  AMÉLIORATIONS  │
│   & PRODUCTION  │    (Combat auto)        │   & PRESTIGE    │
│                 │                         │                 │
│ ⚡ Essence      │   ⭕ Joueur             │ Upgrades ✦      │
│ ✦ Fragments    │   💥 Projectiles        │ Talents         │
│ 📈 Production   │   👾 Ennemis            │ Consolidation   │
│                 │                         │                 │
│ Générateurs     │   HUD de vague          │ Aide & Jalons   │
└─────────────────┴─────────────────────────┴─────────────────┘
```
